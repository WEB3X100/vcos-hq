# VCOS HQ Project

## Vision

VCOS HQ is the command brain for agent-assisted execution across NeuralSync, client delivery, production systems, and domain packs.

## Outcome

Make it possible for Claude, Codex, and teammates to coordinate multiple projects without reloading massive context or scattering decisions across chat.

## Operating Thesis

- ClickUp tracks execution.
- Drive stores working files.
- VCOS HQ stores protocols, decisions, routing, and compact memory.
- Domain packs execute specialized client or industry work.
