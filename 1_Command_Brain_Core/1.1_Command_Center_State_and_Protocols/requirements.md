# VCOS HQ Requirements

## Hard Requirements

- Agents must load fast-path memory before broad references.
- Domain packs must expose a small README interface.
- Implementation/raw data folders are hidden from default context.
- ClickUp remains the execution source of truth.
- Drive remains the file source of truth.
- Obsidian is a navigation and second-brain UI over VCOS HQ Markdown, not a separate source of truth.
- GitHub is history, issues, PRs, and routine source, not a secrets store.
- New skills require a proven SOP or clear adoption task.
- Do not duplicate memory systems unless there is a clear retrieval or token benefit.
- Add cadence only after context, connections, capabilities, and approval gates are clear.

## Non-Goals

- Do not turn VCOS HQ into a client-specific repo.
- Do not make `gstack-Travel` the headquarters.
- Do not create one new fork or skill for every idea.
- Do not store raw logs or scraped data in active memory.
- Do not paste API keys or secrets into chat or committed files.
