## Product boundary

“Launch the Marketing Mini Intern” means start a **draft-generation mission**. It never means publish to LinkedIn.

Castle governs missions, evidence, feedback, and approvals. Hermes produces artifacts. Telegram is the activation and notification surface. LinkedIn publishing remains a separate human action until a later phase receives explicit written approval and security review.

After a supervised week, the system may become a **candidate** for a separate governed autopost phase. Time alone never promotes it: voice/tone accuracy, factual safety, lead-magnet quality, rollback, monitoring, and explicit written authorization must all pass first.
