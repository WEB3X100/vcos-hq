# AI Native Company Arsenal Map

Purpose: compact Graphify/GBrain/Obsidian seed for using the VCOS Arsenal to build an AI-native service company and software factory.

## Core Pattern

VCOS HQ is the command brain. The Arsenal provides reusable capabilities. Projects and domain packs execute the work. Graphify maps relationships before broad reads. QMD routes agents to relevant local files and snippets. GBrain recalls curated context. Obsidian keeps the human oriented.

Every serious workflow should become:

`sensor -> policy -> tool -> quality gate -> output -> metric -> learning update`

## First Factory Loops

### Command Brief

Use fast-path HQ files, GBrain, Graphify, QMD, and ClickUp context to produce the morning cockpit: active outcomes, blockers, decisions needed, agent next actions, and approval queue.

### Software Factory

Use GStack/GSD for specs and reviews, Codex/Claude for implementation, Browser Harness for browser workflows, Impeccable for UI polish, CodeBurn for cost tracking, and Caveman for concise handoffs.

### Brand and Design

Use Design Extract to capture reference design systems and Impeccable to critique and polish outputs. Save only distilled brand/design capsules into HQ memory.

### Revenue Ops

Generalize Career Ops into VCOS opportunity ops: collect leads, score fit, generate drafts, track pipeline, keep human approvals before external communication.

## Guardrails

- Do not import cloned repo source trees into GBrain by default.
- Do not let QMD become a parallel source of truth; it indexes approved Obsidian/HQ/project collections.
- Do not expose graph outputs publicly without review.
- Do not connect browser automation to sensitive accounts without approval.
- Do not publish, send, mutate CRM, spend, deploy, delete, or finalize client-facing strategy without human approval.
- Promote a tool to a skill only after repeated value or a specific adoption task.
