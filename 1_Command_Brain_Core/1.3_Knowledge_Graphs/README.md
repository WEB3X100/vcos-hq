# VCOS Knowledge Graphs

Purpose: keep Graphify outputs, Obsidian graph imports, and lightweight RAG routing organized without turning VCOS HQ into a raw dump.

Canonical protocol: `1_Command_Brain_Core/1.1_Command_Center_State_and_Protocols/graphify-obsidian-rag-architecture.md`.

## Folder Roles

| Folder / file | Role |
| --- | --- |
| `registry.md` | Index of approved graphs, source folders, query commands, and Obsidian import paths |
| `imports/` | Quarantined Graphify Obsidian/wiki imports, one subfolder per source |
| `summaries/` | Curated summaries promoted from graph imports into HQ memory |

## Rule

Graphify outputs are maps, not truth. Source files remain in their owning project, domain, repo, Drive folder, or ClickUp task.
