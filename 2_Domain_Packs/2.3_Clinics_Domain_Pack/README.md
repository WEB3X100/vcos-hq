# Clinics Domain Pack

Clinics is a specialized limb for clinic receptionist, patient intake, lead management, and voice AI workflows.

## Interface

Use this domain for:

- Clinic receptionist workflows
- Patient intake / lead triage
- Clinic voice AI templates
- Customer success lead management
- Clinic proposal and demo flows

## Inputs

- Clinic/client name
- Intake source
- Current workflow
- Demo deadline
- Compliance sensitivity
- Owner
- ClickUp task link

## Outputs

- Scoped workflow
- Demo plan
- Follow-up process
- Automation checklist
- Client-ready proposal
