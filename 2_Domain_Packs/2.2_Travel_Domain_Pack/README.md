# Travel Domain Pack

Travel is a specialized limb. VCOS HQ remains the command brain.

## Interface

Use this domain for:

- Travel CRM workflows
- Amax/Odoo CRM work
- Travel lead intake and follow-up
- Travel proposal decks
- Travel content calendars
- Travel client weekly briefs

## Inputs

- Lead source
- Client/traveler profile
- Trip intent
- Budget and urgency
- Current CRM status
- Owner
- Drive assets
- ClickUp task link

## Outputs

- Clean CRM entry
- Follow-up sequence
- Proposal/deck
- Delivery checklist
- Weekly client brief

## Routing

- Strategy and shared SOPs stay in VCOS HQ.
- Travel-specific execution goes to `gstack-Travel`.
- Working files stay in Drive.
- Ownership, deadlines, and blockers stay in ClickUp.

## Hidden Implementation

Do not read `implementation/` by default. Read it only when a travel task explicitly needs deeper context.
