# 7 VCOS Interns

Purpose: deployable Mini Intern workspaces — identity, capabilities, content pipelines, and generation trackers — separate from department skill packs (`4.3`) and project workspaces (`3`).

## Rule

- **Skill packs** (`4_Reusable_Systems_and_Skills/4.3_Department_Skill_Packs/`) define *what* a department can do.
- **VCOS Interns** (`7_VCOS_Interns/`) define *who* is running work for a specific brand/client lane, with local backlog, trackers, and handoff packets.

Every intern folder must declare:

1. Owning department (from `department-capability-map.md`)
2. Business lane (public acquisition, client demo, internal proof)
3. Linked employee repo path (if any)
4. Approval gates before public spend or publish

1. Read `intern-registry.md`
