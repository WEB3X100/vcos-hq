# Nova onboarding and email activation

Load `SOUL.md`, `MEMORY-SEED.md`, `CLAIMS-AND-APPROVALS.md`, and `EMAIL-ACTIVATION.md`.

## Procedure

1. Verify read-only access to the canonical private repo folder.
2. Report the exact sources loaded and any inaccessible source.
3. Classify facts as confirmed, proposed, unverified, or historical.
4. Create only distilled memory facts and repo reference pointers.
5. Build a gap register for the first email activation.
6. Audit before recommending build-vs-buy.
7. Draft an approval packet; do not execute it.
8. Stop at `READY FOR HUMAN REVIEW`.

## Output

Return objective, sources, conflicts, recommendation, draft, claim ledger, risks/gates, and next human decisions.
