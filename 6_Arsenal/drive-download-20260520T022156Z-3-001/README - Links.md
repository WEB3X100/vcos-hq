# Resources — I Tried 100+ Claude Code Skills. These 6 Are The Best

## Files in this folder
- **6-best-claude-code-skills-resource-guide.pdf** — Companion resource guide with the install commands and details for all six skills/plugins covered in the video.

## External links
- **Skill Creator (Anthropic official):** install via `/plugin install skill creator` inside Claude Code
- **Superpowers plugin (community, ~150K stars):** install via plugin marketplace (see resource PDF)
- **GSD (Get Sh*t Done) plugin:** install via plugin marketplace; run `/gsd-help` after install
- **Context Mode plugin:** install via plugin marketplace, then restart Claude Code; check savings with `/contextmode:ctx-stats`
- **ClaudeMem plugin:** install via plugin marketplace ONLY (do NOT run `npm install` from the repo — hooks won't register)
- **Front-End Design (Anthropic official):** install globally
- **/review and /ultra-review:** built into Claude Code 2.1.86+ — no install required
