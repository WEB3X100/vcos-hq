# Department Skill Packs

Purpose: install validated VCOS capabilities into specialized Mini Interns without creating one overloaded mega-agent.

Each department pack should contain:

- `capabilities.md` — what the intern can do now
- `orchestration.md` — how capabilities combine into workflows
- `least-privilege.md` — tools, secrets, and access boundaries

Do not copy every skill into every department. Departments consume each other's outputs through handoff packets.
