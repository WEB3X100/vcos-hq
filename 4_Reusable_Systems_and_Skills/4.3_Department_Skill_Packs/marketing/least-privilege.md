# Marketing Least Privilege

Marketing may draft and generate internal assets, but it does not own external sending, CRM mutation, finance tools, or production deployment approval.

## Allowed By Default

- draft creative briefs
- draft scripts
- create prompt packets
- review public inspiration
- prepare internal demo assets
- prepare draft website copy and layout plans

## Requires Human Approval

- paid media generation that consumes meaningful credits
- public posting or publishing
- live website deployment
- client logo/testimonial use
- claims about performance, savings, revenue, or client results
- sending assets to prospects or clients

## Not Owned By Marketing

- CRM mutation
- WhatsApp/email sending
- calendar link sending
- QuickBooks/finance workflows
- n8n production workflow activation
- credential setup
