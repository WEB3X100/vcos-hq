# Storyboard Patterns

Read this only for Seedance/video work.

## 4-Second Hook

Use for scroll-stop motion tests.

```markdown
0.0-1.0s: immediate visual contrast, bold 3-5 word text, subject or object enters frame.
1.0-2.5s: reveal the business pain or surprising contrast.
2.5-4.0s: hold the clearest frame and end on the next-question moment.
```

## 6-Second Hook

Use for LinkedIn first-frame tests.

```markdown
0.0-1.5s: high-contrast opening, fast but readable motion.
1.5-3.5s: show the old way failing or the hidden cost.
3.5-6.0s: reveal the new mechanism or proof object.
```

## 8-Second Concept Clip

Use for problem-to-solution visuals.

```markdown
0.0-3.0s: scroll-stop with clear pain.
3.0-6.0s: visual switch or camera change that introduces the Mini Intern mechanism.
6.0-8.0s: end on a clean CTA or curiosity loop.
```

## 15-Second Educational Clip

Use only when there is enough structure to avoid slow pacing.

```markdown
0.0-3.0s: scroll-stop.
3.0-7.0s: context and simple proof.
7.0-11.0s: visual switch / re-hook / B-roll reset.
11.0-15.0s: CTA, proof frame, or next-step question.
```

## Pacing Rules

- 0-3 seconds: prioritize high contrast, clear subject, and dynamic motion.
- Clips longer than 8 seconds require at least one visual switch or re-hook.
- Educational clips should use a Visual Pacifier when the concept is abstract or explanation-heavy.
- Avoid chaotic motion that makes on-screen text unreadable.
- Avoid slow pans unless the subject is already visually compelling.
- If the human rejects pacing as slow, add a negative constraint here before the next generation.

## Visual Pacifier Examples

- hands sorting lead cards into clean piles
- CRM tiles snapping into place
- sticky notes moving from chaos to order
- inbox messages being automatically labeled
- calendar slots lighting up one by one

## Seedance Prompt Add-On

Append a pacing instruction to video prompts:

```text
Keep motion clear and purposeful. Use one strong visual switch if longer than 8 seconds. Preserve text legibility. Do not use chaotic camera movement.
```
