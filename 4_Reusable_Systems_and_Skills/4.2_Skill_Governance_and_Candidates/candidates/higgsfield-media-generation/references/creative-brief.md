# Creative Brief

Use this before writing Higgsfield prompts. Keep it concise; the goal is a shared design concept, not a bloated strategy memo.

## Required Brief

```markdown
## Creative Brief

- Asset type:
- Business lane:
- Audience:
- Funnel stage:
- Desired viewer belief shift:
- Visual Format Inversion:
- Idea Explosivity / Shock Score:
- Core message:
- Required on-screen text:
- Visual-Audio Alignment:
- Main subject:
- Scene / environment:
- Mood:
- Brand notes:
- Required reference assets:
- Product fidelity requirements:
- Platform / placement:
- Creative test variable:
- Proof or claim source:
- Negative constraints:
- Approval status:
```

## Rules

- If the visual vision is vague, ask targeted questions before prompt writing.
- For thumbnails and short clips, on-screen hook text should follow the 3-5 Word Rule unless there is a strong reason not to.
- Shock Score below 70 should be revised before generation unless the asset is purely internal.
- For public AgentOSync media, state whether the asset is awareness, education, proof, or conversion.
- Amax/client-specific details remain internal unless explicitly approved for public use.
- If using a metric, testimonial, dashboard, logo, or named company, cite the source or mark it as unapproved.
- If product fidelity matters, require a reference asset and explicitly forbid packaging, label, color, shape, logo, or product text changes.
- For creative testing, identify the variable being tested so batch outputs can be compared.

## Visual Format Inversion

Before prompting, name the expected format in the niche and the inversion.

Example:

```markdown
- Expected format: dark AI dashboard screenshot with generic robot imagery.
- Inversion: bright physical office scene with a simple missed-lead handoff visual.
```

## Visual-Audio Alignment

The visual should make the hook easier to understand. If the spoken/written hook says "your leads are leaking between tools," the visual should show leakage, handoff failure, or scattered systems, not a generic futuristic interface.
