# UAT Rubric

Use this as a literal pass/fail checklist before generation.

```markdown
## Media Generation UAT

- Asset:
- Model route:
- Business lane:
- Approval status:

### Four Hook Commandments

- Alignment: Pass/Fail - <one sentence>
- Speed to Value: Pass/Fail - <one sentence>
- Clarity: Pass/Fail - <one sentence>
- Curiosity: Pass/Fail - <one sentence>

### Production Checks

- Text legibility: Pass/Fail - <one sentence>
- Scene specificity: Pass/Fail - <one sentence>
- Model/settings fit: Pass/Fail - <one sentence>
- Claim safety: Pass/Fail - <one sentence>
- Human approval gate: Pass/Fail - <one sentence>

### Decision

- Generate now? Yes/No
- Required revision:
```

If any Four Hook Commandment fails, do not generate. Rewrite the brief/prompt first.
