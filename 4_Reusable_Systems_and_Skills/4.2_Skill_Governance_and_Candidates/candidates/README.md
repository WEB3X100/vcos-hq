# Skill Candidates

This folder holds SOPs that may become permanent skills.

## Promotion Rule

Promote a SOP only after 3 successful uses with clear value.

## Candidate Structure

```text
4_Reusable_Systems_and_Skills/4.2_Skill_Governance_and_Candidates/candidates/<candidate>/
├─ SKILL.md
├─ references/
├─ scripts/        # optional deterministic helpers
└─ examples/       # optional test fixtures
```

Current NeuralSync generation candidates:

- `neuralsync-brand-kit/` — shared brand resolver and approval contract.
- `neuralsync-proposal-generation/` — evidence- and pricing-safe PDF proposal workflow.
- `neuralsync-slide-deck-generation/` — editable PPTX/PDF deck workflow with two-brief acceptance gate.
