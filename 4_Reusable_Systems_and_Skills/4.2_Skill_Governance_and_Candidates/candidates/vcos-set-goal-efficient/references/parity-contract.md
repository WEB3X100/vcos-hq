# Production Parity Contract

`vcos-set-goal-efficient` is successful only if it preserves the completion integrity of `vcos-set-goal`.

## Required parity

- Goal contract with three to seven observable truths.
- One binary non-LLM check before implementation.
- Exclusive file ownership before parallel writes.
- Draft-only approval posture when uncertain.
- Independent Skeptic evaluator every cycle; scope may be compact for mechanical work.
- Every passed truth points to a path, command, screenshot, diff, or decision record.
- Explicit complete, blocked, max-cycle, or approval-gate stop.
- Human can review the result without reading the full chat.
- Atomic completion requires every truth/check, binder readiness, ownership reconciliation, and the independent verdict to pass together.
- Council-style review for strategy, business, offer, product, and public-facing goals.

## Allowed efficiency changes

- Replace full conversation forks with a task-local context packet.
- Replace model-written evidence tables with deterministic scripts or Sentinel updates.
- Combine lanes when there is no true parallelism.
- Use lower-cost models for reversible mechanical work.
- Review only changed findings after remediation.
- Use a smaller binder when it remains inspectable.

## Forbidden efficiency changes

- No independent per-cycle review.
- Narrative claims marked pass without evidence.
- Model-tier claims the runtime did not enforce.
- Shared writable files between concurrent agents.
- Hidden approval bypasses.
- Unbounded auto loops.
- Quality comparison where the experimental run saw the control output.
