# Hyperframes Project Structure

Use this when creating or evaluating a Hyperframes project for VCOS.

## Minimal Project

```text
video-projects/<slug>/
├── index.html
├── compositions/
├── assets/
├── renders/
├── hyperframes.json
├── meta.json
└── STORYBOARD.md
```

## Recommended VCOS Additions

```text
video-projects/<slug>/
├── HANDOFF.md
├── QA.md
└── prompt-and-assets-log.md
```

## Metadata To Capture

- project id
- dimensions
- fps
- duration
- platform
- owner department
- source assets
- approval status
- output path
- claims requiring proof

## Brand Token Rule

Each project should copy in its own brand tokens and assets so the project is portable.

Do not ship third-party/example brand assets. Replace demo logos, colors, handles, and brand guideline images before public use.
