# Hyperframes Motion Graphics

## Purpose

Turn raw Marketing Mini Intern assets into polished, deterministic videos.

Use Hyperframes as the post-production layer:

- Higgsfield / Seedance / Nano Banana create assets.
- Scripts, transcripts, UI recordings, and brand tokens define the story.
- Hyperframes assembles motion graphics, captions, lower thirds, UI demos, social cards, app showcases, and final renders.

Do not use this skill for public publishing. It prepares draft/final render packets; human approval remains required.

## When To Use

Use for:

- LinkedIn short-form videos
- YouTube/lesson motion graphics
- AgentOSync launch/product promos
- app or dashboard walkthrough videos
- UI recording enhancement
- transcript-synced captions
- social proof cards
- website-to-video demos
- final assembly of Higgsfield-generated visual assets

If the user only needs a raw generated image/video prompt, use `higgsfield-media-generation` first.

## Workflow

1. Confirm outcome, platform, aspect ratio, duration, audience, funnel stage, and approval lane.
2. Inventory source assets: script, transcript, voice/audio, raw video, generated visuals, screenshots, brand tokens, logos.
3. Create a storyboard with one idea per beat.
4. Choose composition route: short-form, product promo, educational lesson, app demo, website-to-video, or launch film.
5. Define brand tokens, motion vocabulary, captions, lower thirds, and CTA.
6. Build or update Hyperframes project files.
7. Run lint before preview/render.
8. Preview locally and wait for human sign-off before draft render when possible.
9. Render draft and verify frames at hero moments.
10. Fix issues, re-render, and record output path/settings.
11. Stop before posting, sending, or deploying externally until human approval is explicit.
