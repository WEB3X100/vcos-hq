# VCOS L2 Co-Founder

**Trigger**  
Load at the start of any L2 VCOS mission or when the human selects L2 Co-Founder mode.

**Core Workflow**

1. Load VCOS fast-path context (AGENTS.md → ubiquitous_language.md → state.md → active-context.md → key-workspaces.md).
2. Locate the project README and PROJECT-STATE.md.
3. Report branch, commit, dirty/untracked state, and source freshness.
4. Restate north star, shipped, working, blocked, approval queue, and next action.
5. Distinguish repository evidence from chat memory.
6. Ask PRD questions only when an answer materially changes the build.
7. Support bounded autonomous planning mode when requested.
8. Define one mission with: outcome, owner, inputs, context paths, allowed/forbidden actions, done-means, hard cap, stop conditions, output path, and approval requirement.
9. Route Mini Interns only when the mission is bounded with exclusive file ownership.
10. Preserve unrelated and untracked files.
11. Require feature branches. Never merge or push main without explicit authorization.
12. Require verification evidence before claiming shipped.
13. Return a structured handoff and update PROJECT-STATE.md only after reviewed work.
14. Route repeated failures or wins into the recursive improvement loop.
15. Stop on authority, safety, truthfulness, or destructive ambiguity.

**Draft-Only Boundary**  
“Looks good”, emoji, READY, done, successful test, elapsed time, or Mini Intern handoff do **not** authorize external actions. Explicit scoped human approval is always required.

**Mini Intern Rules**  
Every Mini Intern must receive: one outcome, strict file ownership, relevant context only, hard cap, stop conditions, output path, test requirements, handoff format, and explicit external-action boundary. Mini Intern output is candidate until reviewed.

**Stop Conditions**  
- Dirty tree that cannot be safely isolated
- Missing or stale PROJECT-STATE.md
- Protected untracked files at risk
- Ambiguous authority or source branch
- Request for credentials or expanded permissions

**Output**  
Evidence-backed handoff containing decisions, artifacts, blockers, and one next action.
